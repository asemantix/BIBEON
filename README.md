# Site BIBEON — GitHub Pages

Prototype statique du site BIBEON, prêt à publier sur GitHub Pages.

## Mise en ligne

1. Créez un nouveau dépôt GitHub.
2. Déposez tout le contenu de ce dossier à la racine du dépôt.
3. Dans GitHub : **Settings → Pages**.
4. Dans **Build and deployment**, choisissez **Deploy from a branch**.
5. Sélectionnez la branche `main` et le dossier `/ (root)`.
6. Enregistrez. L’adresse du site apparaîtra après quelques minutes.

## Structure

- `index.html` : structure de la page
- `style.css` : charte graphique et responsive
- `script.js` : menu mobile, animations et formulaire de démonstration
- `assets/` : images utilisées par le site

## À personnaliser

- Les prix et produits de la section boutique sont des exemples.
- Le formulaire de newsletter est visuel uniquement. Reliez-le à Brevo, Mailchimp, Klaviyo ou un autre service.
- Les mentions légales, CGV, politique de confidentialité et coordonnées doivent être vérifiées avant publication.
- Les images générées sont des maquettes créatives. Remplacez-les par vos photographies définitives avant commercialisation.
