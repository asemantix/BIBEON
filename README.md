# BIBEON — site avec les médias réels

Cette version intègre :
- les vrais visuels du biberon ;
- les coloris ;
- les visuels avec dose de lait ;

## GitHub Pages
Déposez tous les fichiers et le dossier `assets` à la racine du dépôt, puis activez :
Settings → Pages → Deploy from a branch → main / root.
