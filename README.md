# Site BIBEON — version conforme à la maquette approuvée

Cette version reprend la page avec :
- la grande image émotionnelle parent-bébé ;
- le biberon mis en avant ;
- une présentation commerciale destinée au client ;
- aucune planche technique de fabrication ;
- aucun prix inventé ;
- un bouton « Me prévenir » avant l’ouverture des ventes.

## Mise en ligne avec GitHub Pages

1. Créez un nouveau dépôt GitHub.
2. Déposez tous les fichiers à la racine du dépôt.
3. Ouvrez `Settings` → `Pages`.
4. Dans `Build and deployment`, choisissez `Deploy from a branch`.
5. Sélectionnez `main` puis `/root`.
6. Enregistrez.

## Avant de vendre réellement

Le formulaire d’attente est visuel uniquement. Il doit être relié à un service
comme Brevo, Mailchimp, Shopify ou WooCommerce.

Le prix doit être ajouté uniquement après calcul du coût de revient, de la TVA,
des commissions, de la logistique et de la marge.
